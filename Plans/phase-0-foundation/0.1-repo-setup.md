- Node.js 20+ installed locally
- pnpm 9+ installed (`npm install -g pnpm`)
- Git configured with WorkOS-signed commit identity

- `../CONTEXT.md`

## Objective
Scaffold the monorepo structure for the Medical CRM inside the existing claims platform repo. End state: empty Next.js app, empty Hono API, shared packages, Turborepo config.

## Approach

### If claims platform monorepo does not yet exist
1. Create new GitHub repo (private, under user's org): `medical-platform`
2. Initialize: `pnpm init`
3. Install Turborepo: `pnpm add -D turbo`
4. Create the folder structure below

### If claims platform monorepo exists
1. Clone it locally
2. Create a new branch: `git checkout -b step-0.1-crm-scaffold`
3. Add CRM apps/packages alongside existing claims apps

### Folder structure to create

```
medical-platform/
├── apps/
│   ├── crm-web/                  ← NEW: Next.js 15 App Router
│   └── crm-api/                  ← NEW: Hono API
├── packages/
│   ├── db/                       ← shared Postgres client, schema, migrations
│   ├── auth/                     ← shared WorkOS middleware
│   ├── ui/                       ← shared shadcn components
│   └── config/                   ← shared TS/ESLint/Tailwind

├── .github/

├── turbo.json
├── pnpm-workspace.yaml
├── package.json
├── .gitignore
├── .env.example
└── README.md
```

### Commands

```bash
# From monorepo root
pnpm dlx create-next-app@latest apps/crm-web \
  --typescript --tailwind --app --no-src-dir \
  --import-alias "@/*" --no-eslint

# Hono API
mkdir -p apps/crm-api/src
cd apps/crm-api
pnpm init
pnpm add hono @hono/node-server
pnpm add -D typescript tsx @types/node

# shadcn/ui setup (from apps/crm-web)
cd ../crm-web
pnpm dlx shadcn@latest init
# Choose: New York style, Slate base, CSS variables, use @/components alias

# Add shadcn components we know we'll need
pnpm dlx shadcn@latest add button input textarea select dialog dropdown-menu \
  avatar badge card tabs table form label separator popover command sheet toast
```

### Shared packages skeleton

Create `packages/db/package.json`:
```json
{
  "name": "@crm/db",
  "version": "0.0.1",
  "main": "./src/index.ts",
  "types": "./src/index.ts",
  "dependencies": { "postgres": "^3.4.0", "drizzle-orm": "^0.30.0" },
  "devDependencies": { "drizzle-kit": "^0.20.0" }
}
```

Create `packages/auth/package.json`:
```json
{
  "name": "@crm/auth",
  "version": "0.0.1",
  "main": "./src/index.ts",
  "types": "./src/index.ts",
  "dependencies": { "@workos-inc/node": "^7.0.0" }
}
```

## Acceptance criteria

- [ ] `pnpm install` completes without errors
- [ ] `pnpm turbo build` completes without errors
- [ ] `pnpm turbo dev --filter=crm-web` starts Next.js on localhost:3000
- [ ] `pnpm turbo dev --filter=crm-api` starts Hono on localhost:3001 with a `/health` route returning 200
- [ ] `.env` is in `.gitignore` (verify with `git status` — should not show `.env.local`)
- [ ] `.github/workflows/ci.yml` runs lint + typecheck on PR
- [ ] README.md updated with dev setup instructions

## Common issues

- **pnpm workspace not picking up apps** — check `pnpm-workspace.yaml` is at the root and matches folder patterns
- **Next.js build fails on @/ import** — make sure `tsconfig.json` paths match the `--import-alias` used during create-next-app
- **shadcn init asks about Tailwind config** — accept defaults, we'll customize in Phase 4
